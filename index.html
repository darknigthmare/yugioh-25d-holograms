GUIDE RAPIDE
  • Invocation : Glissez une carte, ou sélectionnez-la puis choisissez une zone vide.
  • Invocation Normale : Une seule Invocation ou Pose Normale est autorisée par tour.
  • Tribut : Niv. 5-6 requiert 1 sacrifice, Niv. 7+ en requiert 2.
  • Magie/Piège : Placez-la dans une zone dédiée ; les pièges réagissent à leur timing.
  • Combat : Passez en Battle Phase, cliquez sur votre monstre puis sur une cible rouge.
  • Fin du tour : Le bouton dédié permet de sauter la Battle Phase depuis Main 1.
  • Effet/position : Cliquez ou touchez votre monstre puis choisissez l’action ; R change directement sa position.
  • Extra Deck : Fusion, Synchro, Xyz et Lien utilisent les matériels légaux et les Zones Monstre Extra.
  • Pendule : Activez deux Échelles aux extrémités, puis utilisez le bouton dédié quand il apparaît.
  • Match : Entre les Duels, échangez une carte compatible avec le Side Deck ; le Dueliste autorisé choisit qui commence.
