# Preuves des modèles de Jetons — 11 octobre 2026

Les 240 codes natifs de monstres Jetons ont été construits et rendus par la vraie factory `createHologramMonsterModel`, sur 42 anatomies. Il s’agit d’adaptations procédurales stylisées ; ces preuves ne revendiquent pas une reproduction graphique 1:1 ni une exhaustivité mondiale des éditions physiques.

129 profils s’appuient sur 120 illustrations de Jetons uniques inspectées, les références partagées conservant chaque code natif distinct. 111 profils utilisent une interprétation documentée de leur définition native, même lorsqu’une illustration de carte génératrice existe. Les 3 repères internes qui ne sont pas des monstres ne reçoivent pas de modèle de Duel. Les commémoratives utilisent des silhouettes de duellistes et sont vérifiées séparément dans l’Atlas.

La capture `before/before-gallery.png` montre les mêmes 25 codes avant le raccord : tous utilisaient une seule chèvre. Le fixture avant force l’attribut EARTH pour isoler cette ancienne silhouette ; le rendu après prend les palettes canoniques. `final/after-gallery.png` reprend caméra, éclairage et sélection, avec les anatomies dédiées. Les dix pages `final/all-tokens-01.png` à `all-tokens-10.png` montrent les 240 codes exacts ; les deux pages `final/anatomies-01.png` et `anatomies-02.png` recensent les 42 familles. Toutes les pages finales ont été inspectées et recoupées avec les références. Les sources sont restées identiques entre le début et la fin de la capture.

Le maximum observé dans la factory et sur le GPU est de 5 890 triangles et 5 appels de rendu par modèle. Les attributs sont finis et les bornes restent positives et compatibles avec le plateau. Les poses ont été rendues sans remplacement ni téléversement des buffers géométriques. Après chaque galerie, le renderer rapporte zéro géométrie, texture et programme conservé ; aucune erreur WebGL n’a été enregistrée. Les deux crochets Metal Fiend possèdent leurs articulations gauche/droite. Les tests vérifient aussi le retour neutre, les mouvements réduits et la libération des matériaux d’ombre.

`final/tests.txt` contient les 17 tests ciblés exécutés réellement. `final/construction-audit.json` mesure tous les modèles. `final/webgl-audit.json` contient les identités, familles, nombres d’appels, triangles, buffers stables et empreintes avant/après. `final/non-token-regression.json` compare les 36 modèles non Jeton : tous leurs buffers, couleurs, matériaux, pièces et compteurs sont identiques avant/après. Ces contrôles de source, géométrie et GPU sont distincts de la QA du duel compilé, réalisée par l’agent principal.

Les dossiers `botanical`, `illustrated-exceptions` et `construct-refinement` conservent les preuves ciblées finales des retouches de référence. `references` contient les quatre planches de contact inspectées ; les JPEG originaux, leur provenance et leurs empreintes figurent dans `public/tokens/reference` et dans le manifeste `token-reference-art.json` de l’inventaire de cette vague.

## Environnement d’exécution

Les scripts ont été exécutés avec le dépôt à `/workspace/yugioh-25d-holograms`, les preuves à `/workspace/yugioh-token-models-2026-10-11`, Three.js local, Vite source sur `http://127.0.0.1:5198`, Python Playwright et Chromium `/usr/bin/chromium` en mode headless SwiftShader (`--use-angle=swiftshader --enable-unsafe-swiftshader`). Les scripts ciblés des enfants peuvent utiliser leurs autres ports Vite indiqués dans leurs README. Les copies des scripts conservent exactement leurs chemins absolus exécutés ; elles ne sont pas présentées comme portables. Pour les rejouer ailleurs, adapter explicitement ces chemins et le port local.

Le comparateur de régression crée des modules d’import isolés dans `baseline-imports` : seule la résolution des imports est adaptée ; les deux sources originales avant intégration demeurent dans `before/*.js.txt`. Les dépendances non Jeton sont inchangées. `delivery-index.json` liste chaque original exécuté et sa copie aux octets identiques dans le dépôt. Aucun script historique ni manifeste enfant n’a été réécrit. Les essais intermédiaires sont exclus de cette livraison ; les logs publiés utilisent `.txt`.

`manifest.json` épingle les fichiers livrés et les sources finales. Son propre fichier est exclu de sa liste pour éviter une empreinte récursive. Aucun build ni publication n’a été effectué par ce chantier modèles.
