# Règles natives — lot B, 8 octobre 2026

Les **38 Terrains assignés passent 38 scénarios natifs**, avec un effet réellement appliqué par Terrain et une chaîne officielle résolue. Chaque scénario conserve les messages du core, les décisions et leurs indices, les requêtes et les cartes de fixture. Une activation sans effet observable ne suffit pas à cette couverture.

Le runner utilise le WASM/API 11.0 fourni, le Master Rule 5 et les deux drapeaux SEGOC TCG. Les fixtures sont enregistrées exclusivement avant `start()`. Aucun script Lua, CDB ou binaire WASM n’est modifié ; aucun mode Debug/TestMode, injection après démarrage ou règle simulée JavaScript n’est employé. Une session est fermée et recréée pour chaque scénario.

Validation : `node scripts/audit-native-field-batch-b.mjs`. Le rapport [JSON](artifacts/native-field-batch-b-2026-10-08.json) contient les empreintes du module, du harness, du loader, du runtime et du WASM ainsi que la provenance des scripts de fixture. Les empreintes doivent être régénérées si le harness partagé change avant livraison.

Les cas mesurent notamment les dégâts de véritables attaques, les fenêtres de phases, le placement Snake-Eye en Magie Continue, les coûts natifs, les bonus conditionnels et l’ordre du Deck.
